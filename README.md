# AI Safety Incident Tracker

A web app built with TypeScript to track, filter, and report AI safety incidents. Created as part of the HumanChain internship assignment.

## 🚀 Features

- View a list of AI incidents with severity filters.
- Navigate to detailed incident views.
- Report new incidents through a form.
- Fully responsive UI built with HTML, CSS, and TypeScript.
